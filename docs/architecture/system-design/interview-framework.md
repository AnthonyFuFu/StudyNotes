# 系統設計面試答題框架

``` mermaid
flowchart LR
    S1["Step 1<br>明確需求"] --> S2["Step 2<br>估算規模"] --> S3["Step 3<br>高層設計"] --> S4["Step 4<br>深入設計"] --> S5["Step 5<br>討論瓶頸"]
```

| 步驟 | 要回答的問題 |
|------|-------------|
| **Step 1：明確需求** | 功能需求：支持哪些功能？<br>非功能需求：QPS、並發量、可用性要求 |
| **Step 2：估算規模** | 每日 DAU 是多少？<br>讀寫比例？<br>需要多少台服務器？ |
| **Step 3：高層設計** | 畫出核心架構圖 |
| **Step 4：深入設計** | 資料庫設計<br>核心流程設計<br>關鍵問題解決方案 |
| **Step 5：討論瓶頸** | 如何擴展？如何解決單點問題？ |
