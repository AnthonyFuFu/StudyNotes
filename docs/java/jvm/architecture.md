# JVM 整體架構

```
┌─────────────────────────────────────────────────────────────┐
│                        JVM 架構                              │
│                                                             │
│  .class 文件 ──→ ┌─────────────────┐                       │
│                  │   類加載子系統    │  （載入、驗證、準備、    │
│                  │  ClassLoader    │   解析、初始化）        │
│                  └────────┬────────┘                       │
│                           ↓                                │
│  ┌────────────────────────────────────────────────────┐    │
│  │              運行時數據區（記憶體模型）                │    │
│  │                                                    │    │
│  │  ┌──────────┐  ┌──────────┐  ┌─────────────────┐  │    │
│  │  │ 程序計數器 │  │ 虛擬機棧  │  │   本地方法棧     │  │    │
│  │  │  (PC)    │  │  Stack  │  │  Native Stack   │  │    │
│  │  │ 線程私有  │  │ 線程私有  │  │   線程私有       │  │    │
│  │  └──────────┘  └──────────┘  └─────────────────┘  │    │
│  │  ┌─────────────────────────────────────────────┐   │    │
│  │  │                  堆 (Heap)                   │   │    │
│  │  │     ┌───────────────┐  ┌─────────────────┐  │   │    │
│  │  │     │   新生代       │  │     老年代        │  │   │    │
│  │  │     │ Eden│S0│  S1  │  │    Old Gen      │  │   │    │
│  │  │     └───────────────┘  └─────────────────┘  │   │    │
│  │  │                   線程共享                    │   │    │
│  │  └─────────────────────────────────────────────┘   │    │
│  │  ┌─────────────────────────────────────────────┐   │    │
│  │  │           方法區 / Metaspace                  │   │    │
│  │  │    類資訊、常量池、靜態變數、JIT 編譯後的代碼     │   │    │
│  │  │                   線程共享                    │   │    │
│  │  └─────────────────────────────────────────────┘   │    │
│  └────────────────────────────────────────────────────┘    │
│                           ↓                                │
│  ┌────────────────┐  ┌────────────────────────────────┐   │
│  │  執行引擎       │  │         本地方法庫               │   │
│  │ ├─ 直譯器      │  │      Native Method Library      │   │
│  │ ├─ JIT 編譯器  │  │                                │   │
│  │ └─ GC         │  │                                │   │
│  └────────────────┘  └────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```
