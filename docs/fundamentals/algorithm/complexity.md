# 複雜度分析

```
常見時間複雜度（由快到慢）：

O(1)        → 常數時間（Hash 查詢、陣列索引）
O(log n)    → 對數時間（二分搜尋、平衡樹查詢）
O(n)        → 線性時間（單次遍歷）
O(n log n)  → 線性對數（快排、合併排序）
O(n²)       → 平方時間（雙層迴圈、暴力比對）
O(2ⁿ)       → 指數時間（暴力枚舉子集）

面試常見複雜度：
  二分搜尋：     O(log n)
  HashMap 操作： O(1) 平均
  快速排序：     O(n log n) 平均，O(n²) 最壞
  合併排序：     O(n log n) 穩定
  BFS / DFS：    O(V + E)（節點 + 邊）
```
