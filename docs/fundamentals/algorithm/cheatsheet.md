# 演算法解題思路速查

```
拿到題目，先問自己：

陣列 / 字串：
  有序？→ 二分搜尋 or 雙指針
  找子陣列 / 子字串？→ 滑動視窗
  需要計數 / 去重？→ HashMap

鏈表：
  需要找中點 / 判斷環？→ 快慢指針
  需要處理頭節點？→ 建虛擬頭節點

樹：
  需要對每個節點做判斷？→ DFS（遞迴）
  需要按層處理？→ BFS（Queue）
  BST？→ 中序遍歷是有序的

動態規劃：
  求最大 / 最小 / 計數 / 是否可行？→ 考慮 DP
  有最優子結構？→ 定義狀態，找轉移方程

排序：
  需要排序後處理？→ 先排序 O(n log n)
  Top K 問題？→ 優先隊列（堆積）O(n log k)
```
